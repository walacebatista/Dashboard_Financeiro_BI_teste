## 📌 Sobre o projeto

O **Dashboard de Vendas BI** simula o painel de uma empresa de tecnologia com vendas ao longo de 2026. Ele reúne os principais indicadores e gráficos em uma única página, com filtros que atualizam tudo em tempo real.

Os dados são **fictícios**, gerados por código com valores reproduzíveis (sempre os mesmos a cada abertura).

## ✨ Funcionalidades

- **KPIs com variação:** Receita, Lucro, Pedidos e Ticket médio, comparando o último trimestre com o anterior (▲ / ▼).
- **Receita x Lucro por mês:** gráfico combinado de barras e linha.
- **Canais de venda:** gráfico de rosca (E-commerce, Loja física e Marketplace).
- **Receita por região:** gráfico de barras horizontais (Sudeste, Sul, Nordeste e Centro-Oeste). Clique em uma barra para filtrar.
- **Tabela de produtos:** receita, margem e pedidos, com ordenação ao clicar no cabeçalho.
- **Filtros:** por região e por canal, com botão **Limpar**.
- **Tema claro e escuro:** segue automaticamente a preferência do sistema.
- **Responsivo:** funciona em desktop e celular.

## 🚀 Como executar

Não precisa instalar nada. Basta clonar o repositório e abrir o arquivo no navegador:

```bash
git clone https://github.com/SEU-USUARIO/dashboard-vendas-bi.git
cd dashboard-vendas-bi
```

Depois, dê um duplo clique em `index.html` (é necessária conexão com a internet para carregar a biblioteca Chart.js).
